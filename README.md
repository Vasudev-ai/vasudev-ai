## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have **Node.js** (version 18 or later) and **npm** installed on your machine.

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/Vasudev-ai/vasudev-ai.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd vasudev-ai
    ```
3.  **Install NPM packages:**
    ```sh
    npm install
    ```
4.  **Set up environment variables:**
    Create a `.env.local` file in the root of the project and add your Google AI API key.
    ```env
    # Your Genkit/Google AI API Key
    GEMINI_API_KEY=YOUR_API_KEY_HERE
    ```
5.  **Run the development server:**
    ```sh
    npm run dev
    ```
    Open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
